# Calculator App 🧮

This is a simple and responsive calculator built using **HTML**, **CSS**, and **JavaScript**. It supports basic arithmetic operations and has a modern UI design.

## 🚀 Features

- Perform basic operations: **Addition (+)**, **Subtraction (-)**, **Multiplication (×)**, **Division (÷)**
- Clear display with **RESET**
- Backspace with **DEL**
- Decimal support
- Responsive layout with button animations
